8. LOCATION ACQUISITION ALGORITHM
==================================================

Do NOT accept the first GPS reading blindly.

Implement:

STEP 1
Request high accuracy location.

STEP 2
Start location acquisition.

STEP 3
Collect multiple location readings.

STEP 4
Read:

latitude
longitude
accuracy
timestamp
altitude if available
speed if available

STEP 5
Discard obviously poor readings.

Example:

accuracy > 50m
→ poor

accuracy > 25m
→ weak

accuracy 10–25m
→ acceptable

accuracy 5–10m
→ good

accuracy <= 5m
→ excellent

These thresholds must be configurable.

Do NOT hard-code them in multiple files.

Create one centralized location accuracy configuration.

==================================================
9. BEST LOCATION SELECTION
==================================================

From multiple readings select the best valid location.

Primary criteria:

1. smallest accuracy radius
2. recent timestamp
3. reasonable movement
4. valid latitude/longitude

Do not simply average unrelated GPS readings.

If readings are unstable:

continue collecting.

Example UI:

"Improving location accuracy..."

↓

↓

↓

Once an acceptable threshold is reached:

"Good location accuracy"
